# @cldmv/configs v1.2.5 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

A development-tooling release. The shared `fix-headers.json` is byte-for-byte unchanged from v1.2.4, so extending repositories see no difference. The only changes are the version in `package.json` and refreshed locked versions of the repository's own lint, format and test tooling in `package-lock.json`.

The published package ships exactly `fix-headers.json`, `README.md` and `LICENSE`. Of those, only `README.md` differs from v1.2.4, and only in its What's New section. `package.json` itself changes only its `version`; none of its dependency ranges moved, and the package still has no runtime dependencies.

---

## 🔧 Dependencies

Every package below is a dev dependency of this repository; none is installed by a consumer of `@cldmv/configs`.

- `eslint` locked 10.11.0 → 10.12.0, within the existing `^10.11.0` range ([#24](https://github.com/CLDMV/configs/pull/24)).
- The `@cldmv` tooling packages, within their existing ranges ([#25](https://github.com/CLDMV/configs/pull/25)):
  - `@cldmv/eslint-plugin-jsonv` 1.0.13 → 1.0.15
  - `@cldmv/jsonv` 1.1.1 → 1.1.3
  - `@cldmv/prettier-plugin-jsonv` 1.1.0 → 1.1.3
  - `@cldmv/vitest-runner` 1.5.1 → 1.5.2
- `chalk` locked 5.6.2 → 6.0.1, a transitive dev dependency pulled in by the new `@cldmv/vitest-runner`. `chalk` 6 declares `engines.node` as `>=22`; it only affects installing the repository's own dev tooling. The CI matrix floor is already Node.js 22.12.0, so CI is unaffected.
