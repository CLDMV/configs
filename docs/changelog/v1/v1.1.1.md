# @cldmv/configs v1.1.1 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

A documentation release: the README is rewritten in the CLDMV package style. No shipped config changed.

---

## 📚 Documentation

- The README is restructured into the CLDMV package layout — **✨ What's New**, **🚀 Key Features**, **📦 Installation**, **🚀 Quick Start**, the config reference, **🔢 Versioning**, **🛠 Development**, **🤝 Contributing** and **🔗 Links** ([#3](https://github.com/CLDMV/configs/pull/3)).
- **Installation** now states the requirement up front: fix-headers v2.0.0 or later, the first release that resolves `extends` and honours `fixCreatedDate`, `normalizeDateFormat` and `strictCreatedDate`.
- The by-URL example pins `v1.1.0`, the first published tag, instead of a `v1.0.0` tag that was never cut.
- **Versioning** spells out the policy as minor (a new config, or a key that only makes a tool stricter where it was silent), major (changing or removing an existing value in a way that alters what the tool writes) and patch (docs, tests and tooling with no change to any shipped setting).
