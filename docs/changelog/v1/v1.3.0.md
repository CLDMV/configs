# @cldmv/configs v1.3.0 Changelog

**Release Date**: October 2026
**Release Type**: Minor
**Branch**: `release/1.3.0`

---

## Overview

The package gains its second shared config: `prettier.json`, CLDMV's house Prettier settings, published as `@cldmv/configs/prettier.json`. A repository extends it from its own `.configs/prettier.config.mjs` instead of keeping a copy of the same `.prettierrc` that every CLDMV repository already carried. The values are the ones the fleet already uses, so a repository that adopts the file sees no formatting change.

The jsonv Prettier plugin that the config loads, `@cldmv/prettier-plugin-jsonv`, is declared as an optional peer dependency. Repositories that format `.jsonv` files install it; repositories that do not can drop `plugins` and the `*.jsonv` override from the config they build on top of the shared file.

`fix-headers.json` is unchanged from v1.2.5.

## ✨ Features

### Shared Prettier config

`prettier.json` sits at the package root, is exposed through `exports` as `./prettier.json`, and is listed in `files`:

| Setting                   | Value                              | Why                                                               |
| ------------------------- | ---------------------------------- | ----------------------------------------------------------------- |
| `useTabs`, `tabWidth`     | `true`, `2`                        | Tab indentation, counted as two columns when measuring width      |
| `printWidth`              | `140`                              | Wide lines keep short call chains and object literals on one line |
| `trailingComma`           | `"none"`                           | No trailing commas                                                |
| `quoteProps`              | `"preserve"`                       | Object-key quoting stays as written                               |
| `bracketSpacing`          | `true`                             | `{ a: 1 }`                                                        |
| `overrides` for `*.xml`   | `printWidth: 300`                  | XML markup does not wrap readably at 140                          |
| `overrides` for `*.md`    | `proseWrap: "preserve"`            | Markdown paragraphs are never re-flowed; one paragraph per line   |
| `overrides` for `*.jsonv` | `parser: "jsonv"`                  | Parse `.jsonv` files with the jsonv plugin                        |
| `plugins`                 | `["@cldmv/prettier-plugin-jsonv"]` | Provides the `jsonv` parser                                       |

A consuming repository creates `.configs/prettier.config.mjs`:

```js
import base from "@cldmv/configs/prettier.json" with { type: "json" };

export default base;
```

and runs Prettier with `--config .configs/prettier.config.mjs`. The README's Quick Start and its new `prettier.json` section cover the setup, the option table, overriding keys, and leaving out the jsonv plugin.

### Optional peer dependency

`@cldmv/prettier-plugin-jsonv` (`^1.1.0`) is a `peerDependency` marked optional in `peerDependenciesMeta`, so npm neither installs it nor warns when it is missing. Prettier itself fails to start when a config names a plugin that is not installed, so repositories without `.jsonv` files should not extend `prettier.json` unchanged.

### This repository uses it

`.configs/.prettierrc` is replaced by `.configs/prettier.config.mjs`, which re-exports `../prettier.json`, and the `format` and `format:check` scripts point at it. The repository is formatted by the exact file it publishes, and the formatting is unchanged.

## 🧪 Tests

- `tests/prettier.test.vitest.mjs` (new) checks every key in `prettier.json` against the options of the installed Prettier, pins the house values and the three overrides, checks that the plugin it names is the declared optional peer, that the repository's own config re-exports it, and that it formats a sample with tabs at the configured width.
- `tests/package.test.vitest.mjs` expects `prettier.json` in the packed tarball and as an export, imports it by its public specifier, and now allows exactly one peer dependency (the optional jsonv plugin) while still requiring no runtime `dependencies`.
- `tests/configs.test.vitest.mjs` requires `prettier.json` among the published configs.
