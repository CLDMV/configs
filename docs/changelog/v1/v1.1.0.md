# @cldmv/configs v1.1.0 Changelog

**Release Date**: September 2026
**Release Type**: Minor

---

## Overview

The first published release of `@cldmv/configs`: CLDMV's shared tool configurations, shipped as plain JSON files that each CLDMV repository extends instead of copying. It ships one config, `fix-headers.json`, holding CLDMV's standard options for [`@cldmv/fix-headers`](https://github.com/CLDMV/fix-headers). The package has no runtime code and no dependencies; npm ships `fix-headers.json`, `README.md`, `LICENSE` and `package.json`. (The repository's earlier `1.0.0` commit was an unpublished package-root bootstrap, not a release.)

---

## ✨ Features

### The shared fix-headers config ([#1](https://github.com/CLDMV/configs/pull/1))

`fix-headers.json` is exposed through `package.json` `exports` as `@cldmv/configs/fix-headers.json` and sets:

- `includeFolders: ["."]` — scan the whole project; ignore files still exclude what they list.
- `useGpgSignerAuthor: true`, `company: "CLDMV"`, `forceAuthorUpdate: true` and `forceLastModifiedAuthorUpdate: true` — take the `@Author` name from the key git signs commits with, written as `Name <CLDMV>`, and always rewrite `@Author`, `@Email` and `@Last modified by` to the detected values.
- `companyName: "Catalyzed Motivation Inc."` and `copyrightStartYear: 2013` — the `@Copyright` holder and the first year of its range.
- `fixCreatedDate: true`, `normalizeDateFormat: true` and `strictCreatedDate: true` — move `@Date` back to the oldest of itself, the file's first commit and its filesystem creation time, write every header date in git's `%aI` form, and fail `--check` on a `@Date` later than the first commit instead of warning.

A repository extends it from its own fix-headers config, by package specifier (`"extends": "@cldmv/configs/fix-headers.json"`) or by a tag-pinned raw GitHub URL, and overrides only the keys that are specific to it. The three date options and `extends` itself need fix-headers v2.0.0 or later.

## 🔧 CI & tooling

- The full CLDMV v4 workflow set (CI, release flow, publishing, CodeQL, scorecard, dependency review, bundle size and the rest), Dependabot config, the CLDMV ESLint and Prettier configs with a pre-commit hook, and an `@cldmv/vitest-runner` test suite that checks every exported JSON file parses, every `exports` entry ships, the keys in `fix-headers.json` are options the installed fix-headers types declare, and `npm pack` publishes exactly the intended files.
